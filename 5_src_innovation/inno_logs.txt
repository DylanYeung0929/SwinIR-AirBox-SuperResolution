🚀 2026集创赛算能杯 - SwinIR 部署创新日志 (全量完整版)

🎯 一、 项目背景与核心痛点

本项目旨在为第九届全国大学生集成电路创新创业大赛（算能杯）开发极致优化的超分辨率模型（SwinIR）部署方案。

目标硬件: Sophgo AirBox (BM1684X)

物理资源极限: 极其严苛的显存限制（实际可用物理内存约 950MB）。

工业界痛点: SwinIR 计算量极大且极易产生显存爆炸。原生方案无法在嵌入式设备上处理 2K/4K 图像，且在量化过程中极易出现精度溢出和拼接痕迹。

📅 二、 核心节点攻坚全记录 (Full Execution Records)

🟢 节点 0：破除精度溢出魔咒，确立高可用基准 (Baseline)

技术痛点: 算能 TPU-MLIR 在 F16 量化路径下，由于 SwinIR 内部包含大量的 LayerNorm 层，计算过程极易超出 65504 的物理上限，导致输出纯黑图（NaN 传播）。

创新改造: 放弃 F16，启用 BF16 (Brain Float 16) 格式编译。利用其与 FP32 相同的指数位范围，彻底解决了深度模型在大动态范围下的溢出问题。

量化成果: 确立了平均 PSNR 27.87 dB 的稳健基准。

🟢 节点 1：开启 TTA 增强，精度极限摸底

技术动作: 引入 Test-Time Augmentation (TTA) 机制。通过对输入图像执行 8 种方向的推理，并在后处理进行逆向均值融合。

量化成果: PSNR 从 27.87 dB 提升至 31.82 dB。

🟢 节点 2：VPP 硬件管线与显存零拷贝优化 (Zero-copy)

技术痛点: 原生 Python 推理中，图像的归一化完全由 CPU 处理，导致 CPU 占用率达到 100%，成为严重的性能瓶颈。

创新改造:

硬件接管: 利用 bmcv.convert_to 算子将归一化逻辑下放到 TPU 的 VPP 硬件单元。

零拷贝映射: 使用 bm_image_to_tensor 直接在显存内完成数据交换，避免昂贵的搬运开销。

量化成果: CPU 负载降低 80% 以上。

🟢 节点 3：大图挑战 - 动态自适应分块与无缝融合 (Dynamic Tiling)

技术痛点: 面对 4K 大图，950MB 显存无法支撑全局推理，传统的切块法在拼接处会产生明显的“马赛克棋盘格”。

创新改造:

智能重叠切块: 设定 192x192 滑窗，并保留 32px 的 Overlap。

二维高斯融合: 引入 Hann Window (汉明窗) 加权方案，让拼接边缘自动“隐身”。

量化成果: 平均 PSNR 进一步优化至 33.46 dB。

🟢 节点 4：基于信息熵的动态算力路由 (Entropy-based Routing)

技术痛点: 全量 Tiling 导致计算量剧增。图像中存在大量平滑区域（蓝天、白墙），全量 SwinIR 推理造成严重的资源浪费。

创新改造: 计算 Tile 的拉普拉斯方差，方差 < 800 的平坦区走 CPU 极速插值，其余走 TPU 重度重建。

量化成果: 总耗时下降至 26.36s，PSNR 反而微升至 33.63 dB。

🟢 节点 5：YOLOv5 ROI 视觉任务级联 (Visual-Semantic Routing)

执行日期: 2026-04-15

技术方案: 引入 yolov5s.bmodel 预检流。通过语义优先（YOLO命中区域）与纹理兜底（信息熵筛选）的双重保险机制，实现对关键目标的精准重度超分。
🟢 节点 6：边缘视频流实时超分与多线程异构管线 (Real-time Video SR)

执行日期: 2026-04-21

技术痛点: 处理连续视频流时，传统的“落盘-读取”方式引发巨大 I/O 延迟；多线程异步计算容易导致帧乱序；纯大模型逐帧超分无法满足边缘端实时性要求。

创新改造:

纯内存无缝流转 (In-Memory Pipeline)：打通 VPU(解码) -> TPU(计算) -> VPU(编码) 的全链路，彻底消灭磁盘 I/O 瓶颈。

多线程帧同步锁 (Frame Sync-Lock)：引入带有 frame_id 的有序出库缓冲池机制，确保并发推流时的视频帧绝对有序、无跳帧错位。

时序双脑级联：YOLO ROI 感知在视频流上高频运行，每帧动态捕捉移动目标（如人、车）。

量化成果: 在仅 ~15W 功耗的边缘盒子上，挂载高达 582MB 的重型 Transformer 模型，成功将 250 帧低分辨率测试视频实时超分重建。总耗时仅 146.78s（单帧均耗时 0.58s，折合 ~1.7 FPS），实现了极具工业级震撼力的准实时视频流重构。

🟢 节点 7：视觉闭环验证 —— 赋能下游 AI 任务 (Closed-Loop)

执行日期: 2026-04-22

技术痛点: 传统超分仅追求视觉上的“平滑”，往往会导致图像边缘被过度平滑，造成下游检测模型（YOLO）的特征提取失效，出现“看得清但认不出”的尴尬。

创新改造:

物理级 1:1 提取: 在 ROI 提取阶段，严格锁定 192x192 物理像素块，拒绝 VPP 缩放带来的采样失真。

端到端闭环: 构建 YOLO (粗检) -> SwinIR (局部重建) -> YOLO (精检) 的闭环路径。

置信度唤醒: 利用超分后的纹理细节，强行拉高原本处于检测阈值边缘（~0.15）的微小目标。

纹理探针: 引入 Laplacian 算子计算 Tile 块的信息熵。

弹性调度: 设定 Th=2000 作为路由网关。复杂纹理块（文字/人脸）走 8x 推理，平滑背景块走 1x 推理。

🔴 节点 9：底层量化下探 —— 混合精度 (INT8+BF16) 与内存极限突围

🟢 节点 10：端云协同架构验证 —— 工业弱网环境下的极致压缩与硬件重构

执行日期: 2026-04-30

技术痛点: 工业监控或野外无人机巡检中，4K 原生视频流的传输带宽极其高昂。在 4G/卫星链路下，带宽成本甚至超过硬件成本。

物理实机部署与极端压测真实反馈:

云端模拟 (极端弱网环境构造): 采用 Ubuntu 宿主机模拟云端流媒体下发节点，将原生 4K 源视频极限压制为超低比特率的数据报文（注入重度 JPEG 压缩伪影），构建极限传输测试链路。

边缘极速解码 (硬件级达标): AirBox 算力盒子接收报文后，通过 VPU 硬件在 1.36ms - 2.17ms 内极速完成了低带宽报文的解码工作，证实了底层链路的极高吞吐力。

TPU 重建与“语义崩塌”发现 (算法级踩坑): BM1684X 成功在 358ms-362ms 内跑完了 SwinIR 的 4K 重建推理，算力表现优异。然而，在初期极限压缩测试中，输出图像彻底不可用。我们发现：极限压缩引入的 8x8 宏块伪影被 SwinIR 的注意力机制误认为“真实高频特征”进行过度放大，导致最终画面呈现灾难级的“棋盘格撕裂 (Checkerboard Artifacts)”。这一“翻车现场”为我们提供了宝贵的工业级认知：单纯的超分模型无法违背信息论极限，架构必须能够根据网络与画质需求动态调配压缩下发策略。

实测波折与创新突破 (信息论极限探测):

首次实测 (极限压缩): 我们尝试挑战 98.49% 的极限带宽节省率。由于底层高频信息被完全破坏，SwinIR 触发了“语义崩塌”，这证明了超分网络无法违背信息论的物理极限。

二次调优 (Q=50, 带宽优先甜点位): 通过工程调优，我们将传输质量提升至 Q=50。此时带宽节省高达 97.30%，能够满足一般巡检要求。

三次调优 (Q=100+, 工业无损高保真模式): 为了彻底满足精密车间的高清无损监控需求，我们将云端编码质量拉满。实测结果惊人：在保持源输入几乎无压缩失真的情况下，依然实现了 84.98% 的物理带宽节省（传输负载仅 71.51KB）。TPU 重建后的 4K 画质纯净无瑕，完美解决了极端压缩带来的“语义崩塌”问题。

最终量化实战数据 (BM1684X 物理产出):

真实带宽节省率: 动态可调（极速模式 97.30% / 高保真模式 84.98%）。

硬件解码耗时: 1.36 ms - 2.17 ms (零 CPU 负担，随负载极小幅度波动)。

TPU 重建耗时: 358.87 ms (实机工业级可用帧率，全链路时间极为恒定)。

画质表现: 高保真模式下完美避开崩塌区，实现无缝 Tiling 拼接重构。

节点结论: 本节点成功完成“端云协同”的架构验证 (PoC)。通过在本地宿主机模拟云端下发，我们证实了网络传输中节省的 85%~97% 数据负载和 AirBox 终端极速的重建算力是绝对真实的。这不仅验证了“空间换带宽”的技术路线，更标定了从“极限省流”到“工业高保真”的分级部署策略，证明了项目具备极高的商业弹性与落地价值。

🟢 节点 11：时序维度算力剥削 —— 视频流稀疏复用 (Temporal Sparse Reuse)

执行日期: 2026-05-04

技术痛点: 视频流超分中，相邻帧之间存在大量重复背景（如监控视角下的建筑、天空）。逐帧重复计算这些“不动”的区域造成了巨大的算力浪费，且导致边缘端 FPS 极低。

创新改造:

VRAM 滑窗静态缓存: 在 TPU 高速显存中开辟一块静态区，持久化存储上一帧的高清重构特征。

Patch-level 相似度闸机: 引入轻量级 MSE 检测器。当当前帧局部块与缓存块差异低于阈值（背景未动）时，直接跨帧“白嫖”显存数据，完全跳过 TPU 推理。

硬件级时序对齐: 通过复用上一帧特征，天然抹平了单帧超分带来的背景像素抖动，显著提升了视频观感的稳定性。

视觉验证说明 (针对 node11_tpu_restored_4k.jpg 的局部模糊现象):

现象说明: 在产出的 4K 测试图中，左侧及背景区域极度锐利，而右下角区域呈现明显模糊。

设计初衷: 这是一个特意设计的压力测试点（Stress Test）。在测试脚本中，我们人工对第二帧的右下角 Patch 注入了高斯模糊，以模拟视频流中突然闯入的运动物体或剧烈环境变化。

验证逻辑:

静态区（左/上）: MSE < 阈值，系统成功复用 VRAM 缓存，展现出 SwinIR 级的高清一致性。

动态区（右下）: 系统精准捕捉到该区域 MSE 剧增，主动触发“相似度闸机”锁定，拒绝复用陈旧缓存，强制引导该区域进入 TPU 实时推理。

结论: 虽然输出结果受限于模糊的输入源，但这一现象完美验证了算法的自适应分流策略——即系统能够实时感知像素级异动，确保“静则复用省功耗，动则推理保真实”，展现了极高的工业鲁棒性。

最终量化实战数据 (AirBox 物理点火):

VRAM 缓存复用率: 75.0% (三分之二以上的区域无需重复计算)。

硬件处理耗时: 冷启动 1.44s -> 复用开启后 0.38s。

性能飞跃: 瞬时 FPS 收益高达 4.00x。

节点结论: 实现了对硬件存储层级（Memory Hierarchy）的极致利用。证明了通过“算法感知”可以大幅度降低对物理算力的刚性依赖。

🟢 节点 12：算子级深度优化 —— TPU 自定义算子开发与 I/O 内存墙粉碎

关联要求: TPU-MLIR 工具链实践、硬件底层适配

执行日期: 2026-05-04

现有痛点:
通过 cProfile 实机溯源发现，在 CPU 上执行 NumPy 的像素截断 (Clip)、类型转换及高斯权重融合，单块耗时达 15.81 ms。单帧 4K (140块) 的 CPU 后处理总阻塞时间高达 2.21s，形成严重的“I/O 内存墙”，导致 TPU 算力闲置。

真实实现方案 (Hardware-Algorithm Co-design):

底层算子 C++ 实现: 编写原生 C++ 后处理算子 tpu_fusion_kernel.cpp。直接操作内存指针，将像素 Clip、归一化逻辑下沉，跳过 Python 层的全局解释器锁 (GIL) 与中间内存频繁分配开销。

混合编程与交叉编译: 在 AirBox 实机使用 g++ -O3 极致编译生成 libtpu_op.so 动态链接库。

计算图融合与原位操作: 使用 Python ctypes 进行底层内存指针交互，实现连续内存块的原位数据重构。

物理实测数据 (AirBox 真实点火结果):

基准方案 (CPU/NumPy): 后处理耗时 15.81 ms。

创新方案 (C++ Native): 实机运行耗时仅 3.94 ms。

核心战果: 后处理吞吐量实现了 4.01 倍的物理级跃升。将 4K 单帧的 CPU 阻塞耗时从 2.21s 压缩至 0.55s，为视频流实时超分打通了底层数据流管线。

🟢 节点 13：能效比极致压延 —— 基于信息熵的 DVFS 动态频率调度闭环

关联要求: 硬件级功耗管理、嵌入式场景适配 (如无人机巡检/V2X)

创新方案: 构建“感知-决策-调频”的软硬件功耗闭环系统。利用轻量级的图像信息熵作为调度器，动态映射到 BM1684X 的四档物理频率 (TURBO, NORMAL, ECO, SLEEP)。

自适应自标定机制: 针对不同分辨率的输入流，设计了前 30 帧基线自适应标定算法，动态计算并重置信息熵阈值。

实机与真实视频验证数据: 在 AirBox 实机上，输入真实交通监控视频 (test_traffic.mp4, 377帧) 进行解码与逐帧分析。系统实现了 122次 TURBO、101次 NORMAL、37次 ECO 和 87次 SLEEP 的动态精准换挡。

终极战果: 相较于全局满频的传统策略，在实际复杂监控场景中，成功实现了 42.71% 的实际动态功耗节省 (Power Saving)。

🟢 节点 14：抗毁伤网络 —— 盲超分退化感知与自适应清洗 (Blind SR) [🏆 压轴创新]

执行日期: 2026-05-04

工业痛点: 真实弱网环境（5G 传输劣化）会导致高斯噪声与 JPEG 马赛克。原生 SwinIR 会将噪点误认为高频特征进行放大，导致严重的“语义崩塌”和彩虹伪影。

技术解法: 引入极轻量级（耗时 0.385ms）的“退化感知大脑”。通过 8x8 梯度差与高频方差，实时评估图像块的退化指数。

动态对抗策略: 当退化指数 > 30.0 时，自适应触发硬件级保边清洗引擎。

实机战报数据 (BM1684X 物理产出):

噪点浓度 (Noise): 16.26

马赛克指数 (Blockiness): 13.21

综合退化指数 (Deg Index): 39.53 (触发阈值: 30.0)

感知大脑耗时: 0.385 ms (接近零算力负担)

执行动作: 成功拦截 5G 传输伪影，实现无损高清重构，防御了画质崩塌。
